# Каталог иконок культур

Каталог-план для набора примерно из 130 культур приложения «Мой Посевной». Это реестр соответствий, не сами изображения и не заявление о визуальной проверке всех SVG.

## Лицензия источника

Open Crop Icons: CC0-1.0. Атрибуция не обязательна; ссылка сохранена для прозрачности. Перед включением конкретных SVG необходимо проверить, что файл существует по указанному slug и корректно отображается в Android. Источник: https://github.com/openfarmcc/open-crop-icons/tree/mainline.

## Принципы

- Одна запись на культуру; дополнительные назначения (например, сидерат) должны быть тегами, а не дубликатами.
- Пустой sourceSlug означает, что для культуры нужна собственная иллюстрация или осознанный общий значок.
- Иконки пользовательских культур выбираются из общего каталога и сохраняются по стабильному id.
- Существующие ресурсы приложения сохраняются как безопасный fallback до интеграции набора.
