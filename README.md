# Мой Посевной 🌱

Android-приложение на русском языке: календарь работ для сада и огорода, каталог культур, лунные фазы, заметки и дневник посадок.

## Что включено в начальный MVP

- Главный экран с сезонными подсказками.
- Календарь с выбором даты.
- Приближённый расчёт фазы Луны.
- Каталог стартовых культур с поиском и краткими инструкциями.
- Локальный дневник посадок и заметки по датам.
- Ежедневное локальное напоминание на 09:00.
- Автоматическая сборка APK через GitHub Actions.

## Сборка APK

Каждый push в ветку `main` запускает workflow **Android APK**. Открой вкладку **Actions**, выбери запуск с зелёной галочкой и скачай артефакт `moi-posevnoy-debug-apk`.

Это debug-сборка для тестирования. Для публикации в магазине потребуется отдельная подписанная release-сборка.

## Технологии

Kotlin, Android SDK, Gradle, GitHub Actions.

## Ограничения первой версии

- Сроки посева — общие ориентиры; региональный расчёт ещё предстоит добавить.
- Погодный API и расширенная база культур ещё предстоит добавить.
- Фаза Луны вычисляется приближённо; лунные рекомендации представлены как традиционные и не заменяют агрономические советы.
- Напоминание пока фиксировано на 09:00. На Android 13+ необходимо разрешить уведомления.
- Основные данные хранятся локально; сервер и регистрация не требуются.

Сроки посева зависят от региона, сорта, способа выращивания и погоды. Учитывайте местные агрономические рекомендации.
