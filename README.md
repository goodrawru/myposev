# Мой Посевной 🌱

Русскоязычное Android-приложение для планирования посевов и повседневных работ в саду и огороде.

## Возможности

- Календарь посевов с датами, сезонными подсказками, фазами Луны и заметками.
- Каталог культур: поиск, сроки посева, глубина, сроки появления всходов и советы.
- Пользовательские культуры: добавление, редактирование, удаление, категория и выбор цветной иконки.
- Дневник посадок, история урожая и задачи по уходу.
- Выбор города и климатической зоны; прогноз погоды открывается во встроенном окне официального сервиса.
- PDF-планировщик: выбор года, сезона и разделов, цветной или экономный режим, многостраничный документ и перенос длинного текста.
- Резервное копирование настроек и пользовательских данных в ZIP-архив и восстановление из него.
- Локальные данные без обязательной регистрации и собственного сервера.
- Напоминания и встроенное воспроизведение локальных аудиофайлов с системными медиаконтролами.

## Сборка APK

Рабочая ветка проекта — `rustore`. Push в эту ветку запускает workflow **Android APK**.

1. Откройте вкладку [Actions](https://github.com/goodrawru/myposev/actions).
2. Выберите успешный запуск, относящийся к ветке `rustore`.
3. Скачайте debug APK из артефактов либо release APK из соответствующего релиза, если шаг подписания выполнен успешно.

Релизы: [GitHub Releases](https://github.com/goodrawru/myposev/releases).

## Технологии

Kotlin, Android SDK, Gradle, GitHub Actions, SharedPreferences, AndroidX Media3.

## Ограничения

- Региональные сроки — ориентировочные подсказки, а не гарантия урожая. Учитывайте сорт, микроклимат, грунт, способ выращивания и риск заморозков.
- Фаза Луны рассчитывается приближённо; лунные советы относятся к традиционной практике и не заменяют агрономические рекомендации.
- Для погоды и загрузки внешних страниц нужен интернет.
- Резервная копия хранит данные приложения из SharedPreferences; отдельно сохранённые файлы и фотографии, если они появятся в будущем, могут не входить в архив.

Проверяйте рекомендации с учётом климата и фактических условий своего участка.
