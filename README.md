# Мой Посевной 🌱

Русскоязычное Android-приложение для планирования посевов и повседневных работ в саду и огороде.

## Возможности

- **Место и климатическая зона:** выбор города/региона вручную или попытка определить место по разрешённой геолокации.
- **Региональные сезонные подсказки:** ориентировочная поправка для юга, центральной части, Северо-Запада, Урала, Сибири, Севера и Дальнего Востока.
- **Погода Яндекс:** прогноз выбранного города или координат открывается во встроенном окне приложения через официальный сайт Яндекс Погоды. Внешний браузер и Open-Meteo не используются.
- **Задачи по уходу:** добавление работ с датой, культурой и типом; отметка выполненных задач и удаление из истории.
- **Календарь посевов:** выбор даты, сезонные подсказки, лунная фаза и заметки.
- **Крым и Севастополь:** добавлены в ручной выбор местоположения с ориентировочной южной климатической зоной.
- **Безопасные системные отступы:** верхняя панель учитывает строку состояния Android, в том числе edge-to-edge на Android 15.
- **Каталог культур:** поиск по стартовому списку культур, глубина посева, примерное время появления всходов и советы.
- **Дневник посадок:** локальные записи о культурах и датах посева.
- **Напоминание:** ежедневное уведомление, ориентировочно на 09:00.
- **Встроенный музыкальный плеер** на AndroidX Media3: выбор нескольких локальных аудиофайлов, очередь воспроизведения, пауза/продолжение, предыдущий/следующий трек, перемотка и фоновое воспроизведение с системными медиаконтролами.
- **Интернет-аудио по прямой ссылке**: можно добавить прямой URL на разрешённый аудиофайл или поток MP3/AAC/HLS. Обычные ссылки на страницы сайтов не являются аудиопотоками.
- **Источники музыки**: переход к официальному онлайн-плееру Радио Дача и каталогам Zvukogram/Chosic. Сайты открываются отдельно; приложение не извлекает неофициальные радиопотоки и не встраивает треки без проверки лицензии.
- **Собственная иконка приложения** с ростком.
- **Автоматическая сборка debug APK** через GitHub Actions.

## Сборка APK

Каждый push в ветку `rustore` запускает workflow **Android APK**. Открой вкладку **Actions**, выбери успешный запуск для ветки `rustore` и скачай артефакт debug APK.

Это debug-сборка для тестирования. Для публикации в магазине потребуется отдельная подписанная release-сборка.

## Технологии

Kotlin, Android SDK, Gradle, GitHub Actions, SharedPreferences, встроенный WebView для Яндекс Погоды.

## Важные ограничения

- Список городов пока стартовый, а не полный справочник всех населённых пунктов России. Если GPS не определит подходящее место, можно выбрать ближайший город вручную.
- Региональные сдвиги сроков — грубые сезонные подсказки, а не точный агрономический календарь. Срок зависит от сорта, микроклимата, теплицы/открытого грунта, температуры почвы и риска заморозков.
- Геолокация требует разрешения Android. Приложение использует последнюю известную координату устройства; если её нет, предложит включить геолокацию или выбрать город вручную.
- Для просмотра погоды требуется интернет-доступ к сайту Яндекс Погоды. Страница открывается внутри приложения; если сам сайт недоступен в сети пользователя, актуальный прогноз загрузить не получится.
- Фаза Луны вычисляется приближённо. Лунные советы — традиционная практика и не заменяют агрономические рекомендации.
- Напоминание пока фиксировано на 09:00. На Android 13+ необходимо разрешить уведомления.
- Записи и задачи хранятся локально. Сервер, аккаунт и регистрация не требуются.

## Источники идей

Приложение предназначено для локального планирования посевов и садово-огородных работ; даты и рекомендации следует адаптировать к местному климату и условиям участка.

Сроки посева следует сверять с местными агрономическими рекомендациями и фактической погодой.

## Скачать APK

Успешные сборки публикуются в разделе [Releases](https://github.com/goodrawru/myposev/releases). Для установки выбирайте APK из самого свежего релиза, собранного из ветки `rustore`.

Дополнительно APK сохраняется как артефакт GitHub Actions на 90 дней. Если сборка завершается ошибкой, релиз не публикуется.

**Важно:** это debug APK для тестирования. Он не подписан release-ключом Google Play и предназначен для установки вручную на Android.
