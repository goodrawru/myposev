# Мой Посевной 🌱

Android-приложение на русском языке: посевной календарь для России, каталог культур, лунные фазы, локальные напоминания и офлайн-доступ к основным сведениям.

## Первая версия
- Главный экран с рекомендациями на выбранную дату
- Выбор даты календаря
- Поиск и каталог культур
- Карточки с основными советами по выращиванию
- Информационный лунный блок (традиционные рекомендации, не научный прогноз урожайности)
- Локальное ежедневное напоминание
- Работает без регистрации и сервера

## Сборка APK
Каждый push в `main` запускает GitHub Actions. Открой вкладку **Actions**, выбери успешный запуск и скачай артефакт `my-posev-debug-apk`.

APK для тестирования — debug-сборка. Для публикации потребуется отдельная подписанная release-сборка.

## Технологии
Kotlin, Jetpack Compose, Material 3, WorkManager, Android SDK.

## Важно
Сроки посева зависят от региона, сорта, способа выращивания и погоды. Встроенные сведения являются общими ориентирами, а не заменой местных агрономических рекомендаций. Лунные советы представлены как традиция; убедительных доказательств повышения урожайности за счёт фаз Луны недостаточно.
