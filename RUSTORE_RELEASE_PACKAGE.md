# Материалы для карточки RuStore — «Мой Посевной»

Подготовлено для ветки `rustore`, версия приложения **1.3.6** (`versionCode 18`).

## 1. Название

**Мой Посевной**

Название короче лимита RuStore в 30 символов и совпадает с названием приложения на устройстве.

## 2. Краткое описание (до 80 символов)

Календарь посевов, уход за растениями, задачи, заметки и погода на 7 дней.

## 3. Подробное описание (до 4000 символов)

«Мой Посевной» помогает планировать сезонные работы в саду и огороде, вести записи и не забывать о задачах по уходу за растениями.

**Календарь и планирование**
- Просматривайте календарь по месяцам и годам.
- Используйте сезонные подсказки и сведения о фазах Луны.
- Добавляйте заметки к датам и отмечайте запланированные работы.
- Получайте ежедневные напоминания о выбранных категориях работ.

**Культуры**
- Изучайте встроенный каталог растений с рекомендациями по посеву и выращиванию.
- Смотрите ориентировочные сроки посева, глубину заделки семян и сроки появления всходов, если сведения доступны для культуры.
- Добавляйте собственные культуры, выбирайте для них категорию и значок, редактируйте или удаляйте записи.

**Погода**
- Просматривайте прогноз примерно на 7 дней в карточках.
- Выбирайте населённый пункт вручную или разрешайте определение местоположения.
- В прогнозе отображаются доступные метеопоказатели, включая температуру, облачность, осадки и ветер.
- Для загрузки актуального прогноза требуется интернет. При его отсутствии приложение может показать сохранённые ранее данные.

Источник прогноза — 7Timer!. Координаты выбранного места передаются этому внешнему сервису при запросе прогноза. Подробности приведены в политике конфиденциальности и на экране источника погоды.

**Заметки и резервное копирование**
- Ведите личные заметки и список задач.
- Создавайте PDF-планировщик для печати с календарём и выбранными разделами.
- Сохраняйте резервную копию настроек и пользовательских данных в ZIP-архив и восстанавливайте её при необходимости.

**Без рекламы и обязательной регистрации**
Приложение не требует создания аккаунта, не содержит рекламы и не использует рекламные или аналитические трекеры. Основные записи хранятся локально на устройстве. Интернет используется для загрузки прогноза погоды и открытия ссылок, выбранных пользователем.

Поддержать дальнейшую разработку можно добровольным пожертвованием. Оно является только благодарностью разработчику и не открывает дополнительные функции или преимущества.

**Важно:** сроки посева и другие рекомендации являются ориентировочными. Учитывайте сорт, регион, микроклимат, тип грунта, способ выращивания и фактическую погоду. Фазы Луны и связанные с ними советы имеют справочный характер и не заменяют агрономические рекомендации. Прогноз погоды не гарантирует фактические условия на участке.

## 8. Чувствительные разрешения — пояснения для формы RuStore

**ACCESS_COARSE_LOCATION / ACCESS_FINE_LOCATION — местоположение**
Нужно только для определения координат выбранного пользователем места и получения прогноза погоды для этого места. Пользователь может отказать в разрешении и выбрать населённый пункт вручную. Координаты передаются погодному сервису 7Timer! при запросе прогноза; разработчик не получает их на собственный сервер.

**POST_NOTIFICATIONS — уведомления**
Используется для ежедневных напоминаний о работах, задачах и заметках, если пользователь включил напоминания и разрешил уведомления. При отказе уведомления не показываются, остальные функции приложения остаются доступны.

**RECEIVE_BOOT_COMPLETED — запуск после перезагрузки**
Нужен, чтобы восстановить расписание включённых пользователем ежедневных напоминаний после перезапуска устройства. Сам по себе не используется для сбора данных.

**INTERNET — сетевой доступ**
Используется для запроса прогноза погоды у 7Timer! и открытия внешних ссылок по действию пользователя.

## 9. Декларация данных для консоли

Проверить поля и варианты ответов непосредственно в консоли RuStore перед отправкой:
- Учётные записи: отсутствуют.
- Рекламные SDK и рекламные данные: отсутствуют.
- Аналитические трекеры: отсутствуют.
- Данные, сохраняемые локально: город/координаты выбранного места, задачи, заметки, выбранные культуры и настройки напоминаний.
- Передача третьей стороне: координаты выбранного места (широта и долгота) сервису 7Timer! при запросе прогноза; при определении названия места системный геокодер Android может использовать сетевые службы платформы.
- Данные разработчику на собственный сервер: не передаются; собственного сервера у приложения нет.
- Удаление аккаунта: не применимо, так как приложение не создаёт аккаунты.
- Резервная копия: ZIP создаётся по действию пользователя и сохраняется в выбранное им место.

Не отмечать без проверки, что приложение «не передаёт никакие данные»: координаты отправляются погодному сервису.

## 10. Медиафайлы карточки

Загрузить 4–6 настоящих скриншотов актуальной версии приложения, например:
1. Главный экран/календарь.
2. Подробности выбранного дня и заметки.
3. Карточки прогноза погоды.
4. Каталог культур или добавление пользовательской культуры.
5. Задачи и напоминания.
6. Настройка PDF-планировщика.

Скриншоты должны быть сняты из реально установленной версии, без системных панелей, выдуманных функций и рекламных обещаний. Для телефона: PNG/JPG, каждый файл до 3 МБ, максимальный размер 2160×3840 px. Иконка: PNG/JPG 512×512 px, до 3 МБ, непрозрачный фон по краям.

## 11. Блокеры до отправки на модерацию

1. **Условия 7Timer!:** официальная документация указывает, что данные можно использовать и распространять бесплатно только при некоммерческом использовании, а разработчиков просят уведомить о подключении API. Поскольку в приложении есть добровольная ссылка на пожертвование, до публикации необходимо получить подтверждение, что такая модель использования допустима, либо заменить источник прогноза/убрать погодную функцию до получения разрешения. Не считать этот вопрос закрытым только потому, что API не требует ключа.
2. **Контакт ответственного лица:** в текущей политике указан GitHub Issues, но правила RuStore требуют контактные данные ответственного за обработку данных. Перед отправкой добавьте публичный контактный адрес (например, отдельную почту поддержки) в политику и заполните контакты разработчика в консоли. Не публикуйте личные данные, если для поддержки можно завести отдельный адрес.
3. **Проверка APK на устройстве:** успешная сборка не заменяет установку и ручную проверку подписанного APK на телефоне. Проверить первый запуск, отказ в геолокации, ручной выбор города, прогноз, заметки, уведомления, перезагрузку, PDF и восстановление резервной копии.
4. **Разрешения и декларация данных:** заполнить формы RuStore в соответствии с фактическим поведением приложения, а не только по этому черновику.
5. **Подпись:** загружать только подписанный release APK. Сохранить keystore и пароли вне репозитория; для обновлений должна использоваться та же подпись и увеличенный versionCode.
