# Политика конфиденциальности — «Мой Посевной» (версия RuStore)

Дата редакции: 1 ноября 2026 года.

## 1. Кто отвечает за приложение
Приложение «Мой Посевной» — самостоятельный проект разработчика goodrawru. По вопросам работы приложения и обработки данных можно обратиться через раздел Issues репозитория: https://github.com/goodrawru/myposev/issues.

## 2. Учётная запись, реклама и аналитика
Приложение не требует регистрации, не создаёт пользовательских аккаунтов, не содержит рекламных SDK и не использует аналитические трекеры.

## 3. Какие данные хранятся на устройстве
Выбранный город/регион, координаты выбранного места, задачи, заметки, выбранные культуры и настройки ежедневных уведомлений сохраняются локально на устройстве в хранилище приложения. Эти данные не отправляются разработчику. Пользователь может создать ZIP-резервную копию этих данных и самостоятельно сохранить её в выбранном месте. Удаление приложения обычно удаляет локальные данные приложения; поведение системных резервных копий Android зависит от настроек устройства.

## 4. Геолокация и прогноз погоды
Если пользователь выбирает определение местоположения, приложение использует разрешение геолокации Android для получения координат и системный компонент Geocoder для попытки определить название населённого пункта. Системный геокодер может использовать сетевые службы платформы; приложение не передаёт эти данные на собственный сервер. Пользователь может отказать в разрешении и выбрать город вручную.

При запросе пятидневного прогноза координаты выбранного места (широта и долгота) передаются непосредственно с устройства сервису MET Norway по адресу https://api.met.no/weatherapi/locationforecast/2.0/compact. Приложение отображает источник данных и ссылку на лицензию CC BY 4.0. Собственный сервер проекта не используется. Внешний поставщик может обрабатывать IP-адрес и координаты в соответствии со своими условиями и правилами хранения журналов запросов.

Прогноз является справочным. Его точность и доступность зависят от поставщика, интернет-соединения и фактических условий местности. При отсутствии сети приложение может показать последний успешно сохранённый прогноз.

## 5. Внешние сайты
По явному нажатию пользователя приложение может загрузить сайт Яндекс Погоды во встроенном окне WebView. При таком переходе запросы к сайту и возможная обработка технических данных регулируются условиями и политикой конфиденциальности Яндекса. Приложение не извлекает прогнозные данные из внутреннего API сайта Яндекса.

## 6. Передача данных и сроки хранения
Разработчик не получает перечисленные локальные данные. Локальные данные остаются на устройстве до удаления пользователем, очистки данных приложения или удаления приложения. Координаты передаются внешнему погодному сервису только при запросе прогноза; при определении названия населённого пункта может использоваться системный компонент геокодирования Android.

## 7. Безопасность
Приложение не предоставляет разработчику удалённого доступа к устройству и не использует собственную учётную запись или серверную базу данных. Пользователю рекомендуется поддерживать Android в актуальном состоянии и хранить резервные копии в безопасном месте.

## 8. Права пользователя и обращения
Пользователь может не предоставлять разрешение на геолокацию и выбрать город вручную. По вопросам политики и работы приложения можно написать через https://github.com/goodrawru/myposev/issues.

## 9. Изменения политики
При изменении функций или способов обработки данных эта политика будет обновлена. Актуальная редакция публикуется в репозитории проекта.
